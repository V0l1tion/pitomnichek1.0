ПИТОМНИК · ИНВЕНТАРИЗАЦИЯ — готовый проект
============================================

ШАГ 1. Разместить в интернете (нужен HTTPS — обязателен для камеры и PWA)
 - Проще всего: откройте  app.netlify.com/drop  и перетащите туда ЭТУ папку (nursery-app).
 - Альтернативы: GitHub Pages, Vercel, любой хостинг со статикой.
 - Полученную ссылку открывайте на телефоне.

ШАГ 2. Установка на телефон
 - Android (Chrome): откройте ссылку → меню ⋮ → «Установить приложение»
   (или «Добавить на главный экран»).
 - iPhone (Safari): откройте ссылку → кнопка «Поделиться» → «На экран Домой».
 - После первого открытия приложение работает БЕЗ ИНТЕРНЕТА.

ШАГ 3. Первый запуск
 - Введите код питомника и имя устройства (или нажмите «Сразу с демо-данными»).
 - Создайте площадки: №1, №2, №3. Добавьте растения (фото, цена, количество, себестоимость).

ПЕЧАТЬ ЭТИКЕТОК 43×25 мм
 - Экран «Этикетки» → выберите площадку → «Отметить все» → «Копии = остатку» (по желанию).
 - «PDF на A4» — сетка 4×11 = 44 этикетки на лист, точно под наклейки 43×25 мм.
   В диалоге печати: масштаб 100%, поля — по умолчанию.
 - «Термопринтер» — отдельный PDF, где каждая страница = одна этикетка 43×25.
 - Одна этикетка: в карточке растения кнопка «Этикетка».

СКАНИРОВАНИЕ И ПРОДАЖА
 - «Скан» → «Включить камеру» (разрешите доступ). Повторное сканирование того же кода = +1 шт.
 - На Android распознавание кодов работает офлайн (встроенный механизм браузера).
 - На iPhone используется подключаемая библиотека: нужен интернет при ПЕРВОМ сканировании,
   дальше кэшируется. Либо всегда доступен ручной ввод кода (работает без интернета).
 - «Продать» → остаток уменьшается, продажа (дата, цена, себестоимость, прибыль, устройство)
   записывается в Историю.

ОТЧЁТЫ
 - Отчёты → период (день/месяц/сезон/всё) → выручка, себестоимость, прибыль,
   остатки по площадкам, список «заканчивается (<5 шт)» → «Отчёт в PDF»
   (откроется печатная форма: там «Печать» или «Сохранить как PDF»).

РЕЗЕРВНАЯ КОПИЯ / ПЕРЕНОС НА ДРУГОЙ ТЕЛЕФОН
 - Настройки → «Экспорт данных (JSON)» → файл можно переслать.
 - На другом устройстве: Настройки → «Импорт» → выбрать файл.
