ЧТО НОВОГО В v2
 - Сканер работает на iPhone БЕЗ внешних библиотек (свой офлайн-раскодировщик Code 128).
 - Кнопка «Список» в сканере — выбор сорта вручную, код знать не нужно.
 - Коды сортов — простые числа: 101, 102, 103… (видны в карточке и в списках).
   30 горшков одного сорта = 30 этикеток с ОДНИМ кодом: «Этикетки» → «Копии = остатку».
 - Термоэтикетка 46×20 мм (Honeywell): «PDF для термопринтера» = лента,
   где каждая страница — одна этикетка. Печать с компьютера: масштаб 100%.
 - Партии: карточка растения → «+ Добавить партию» (кол-во + 5 компонентов,
   расчёт по шагам). Остаток растёт, себестоимость продажи = средневзвешенная по партиям.
 - Скидка в продаже: кнопки 5/10/15% или своё значение; сумма и прибыль пересчитываются.
 - Синхронизация между телефонами (Supabase, бесплатно) — см. ниже.
 - Название «Гектары Счастья» + эмблема из файла logo.png.

ЭМБЛЕМА
 1. Обрежьте картинку в квадрат, сохраните как logo.png (рекомендуется 512×512).
 2. Загрузите logo.png в папку nursery-app на GitHub (и замените им apple-touch-icon.png).
 3. Приложение подхватит эмблему в шапке, в приветствии и на иконке телефона.

СИНХРОНИЗАЦИЯ (ЭТАП 2)
 1. supabase.com → Sign up (бесплатно) → New project.
 2. Слева SQL Editor → вставьте и Run:
    create table if not exists docs (
      kind text not null, id text not null,
      doc jsonb not null, updated_at bigint not null default 0,
      primary key (kind, id));
    alter table docs enable row level security;
    create policy docs_select on docs for select using (true);
    create policy docs_insert on docs for insert with check (true);
    create policy docs_update on docs for update using (true) with check (true);
    create policy docs_delete on docs for delete using (true);
 3. Settings → API: скопируйте Project URL и anon public key.
 4. В приложении: Настройки → Синхронизация → вставьте URL и ключ → «Синхронизировать».
 5. То же самое на втором телефоне. Дальше синхронизация идёт сама при появлении сети
    (каждые 60 сек и после изменений). Конфликты: последняя операция побеждает.
 Примечание: удаления площадок/позиций тоже синхронизируются (мягкое удаление).

ПЕЧАТЬ ЭТИКЕТОК
 - A4 под наклейки 43×25: сетка 4×11, масштаб печати 100%.
 - Термо 46×20: PDF-лента, печать с компьютера (Honeywell), масштаб 100%.

РЕЗЕРВНАЯ КОПИЯ: Настройки → Экспорт/Импорт JSON.
