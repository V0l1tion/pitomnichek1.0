ГЕКТАРЫ СЧАСТЬЯ · ИНВЕНТАРИЗАЦИЯ · v3
======================================
Адрес: https://v01ition.github.io/pitomnichek1.0/nursery-app/

ЧТО НОВОГО В v3
 - Коды сортов — 8-значные числа без букв и значков (например 51324567).
   Один код на сорт, у всех горшков сорта он одинаковый.
   Старые короткие коды при первом запуске заменяются автоматически →
   ОДИН РАЗ перепечатайте этикетки.
 - На этикетке (A4 43×25 и термо 46×20) теперь подписан код цифрами рядом с ценой.
 - В списках код пишется как «код 51324567», без «№».
 - Иконка приложения, иконка iPhone и логотип в шапке собираются из вашей эмблемы
   (файл выбирается в сборщике перед скачиванием ZIP): logo.png, icon-192.png,
   icon-512.png, apple-touch-icon.png уже готовы в архиве.
   После загрузки файлов на GitHub переустановите ярлык на телефоне
   (iPhone: удалить ярлык → «Поделиться» → «На экран Домой»;
    Android: удалить приложение → установить заново).

НАПОМИНАНИЕ ПРО v2 (всё работает)
 - Скан офлайн на iPhone и Android; кнопка «Список» — выбор сорта вручную.
 - «Копии = остатку» — по этикетке на каждый горшок сорта (код один).
 - Термо 46×20: PDF-лента (страница = этикетка) для Honeywell, печать с компьютера, масштаб 100%.
 - Партии: карточка растения → «+ Добавить партию»; себестоимость продажи = средневзвешенная.
 - Скидка в продаже: 5/10/15% или своё значение.
 - Синхронизация: Настройки → Синхронизация (Supabase, инструкция и SQL внутри).

РЕЗЕРВНАЯ КОПИЯ: Настройки → Экспорт/Импорт JSON.
